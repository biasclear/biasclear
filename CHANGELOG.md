# Changelog

Versions follow PEP 440. The package version and the rules version are listed separately when they differ.

## 2.0.0a1 (unreleased)

The first release of v2: one rule pack, a Python engine and a TypeScript engine with no runtime dependencies, and a website that runs the rules in the visitor's browser. Alpha. The Python package is what goes to PyPI; the TypeScript engine is not on npm yet.

Package version 2.0.0a1; rules version 2.0.0a5.

The site moved from its preview address to https://biasclear.com/ on 2026-10-06; links in the README, the PyPI readme and the package metadata (`Homepage`) point there.

Test inputs, in `tests/` and in `rules/RULE_CHANGES.md`, are paired with their mirrors and some quote insults. The people, parties, organizations, faith bodies, outlets, schools, awards and programs in them are made up, each with the shape of the name it replaced, and the golden files were made again from the renamed texts: every text raises the same rules on the same words. This file describes each change by its structure.

### Rules version 2.0.0a5 (preview review)

- The institutional sentence-start check skips all following whitespace before deciding whether a lowercase word continues the sentence. Repeated `a.  a ` previously made both engines rescan the remaining text at every period. Mixed and repeated whitespace now have performance regressions in both engines, with semantic controls for assertions, continuations and evidence-backed exceptions. Existing golden-case outputs are unchanged.
- The Method page and six Field Guide entries disclose first-occurrence citation lookup: a cited earlier phrase can suppress an unsourced repetition much later. Citation behavior is unchanged. Copy distinguishes published regression counts from unmeasured accuracy and describes the build checks precisely.

### TypeScript engine

- **`packages/engine/`**: the same rule pack in TypeScript, for browsers and Node, with no runtime dependencies. `scan(text, { domain })` returns what the Python engine returns, in camelCase (`ruleId`, `rulesVersion`, `rulesHash`), with UTF-16 offsets for the DOM. It makes no network calls, uses no host globals and never evaluates code from strings; a test runs the browser bundle in an empty context with code generation from strings turned off.
- **Same results as Python, on non-ASCII text too.** Python's `re` and JavaScript's `RegExp` read `\w`, `\b`, `\d`, `\s` and case-insensitive letters differently outside ASCII. The engine translates each pattern so it reads the text as Python does (rather than moving both engines to ASCII-only rules), and `tests/golden/unicode_parity.json` pins the cases where plain JavaScript would differ. The input cap counts code points, as Python does.
- **Checked against the live Python engine.** `packages/engine/scripts/parity.mjs` runs both engines on every golden text and every swapped pair, in every domain, and fails on any difference; CI runs it against Python 3.10 to 3.14. `rulesHash` is computed at build time and equals Python's `rules_hash`.
- **Built files.** An ES module and one minified browser bundle (global `BiasClear`), both holding the whole rule pack. The build fails if the browser bundle is over its gzip budget; `packages/engine/README.md` gives the sizes and the share of the budget used, and a test keeps them true.
- **A ReDoS guard.** Every translated pattern must finish within its time limit on adversarial strings built from its own words and punctuation (`packages/engine/test/redos.test.ts`).
- **`prepare()`** compiles the rules ahead of a scan, one pattern per call, so a page can spread the work over short tasks. Results are unchanged.
- **Not on npm yet** (`"private": true`). The site serves the browser bundle byte for byte.

### Website (public preview)

- **A static site in `site/`**, built by `scripts/build-site.mjs` into `_site/` and deployed to GitHub Pages by `.github/workflows/pages.yml` (push to `main`, or by hand from `main`; no deploy secrets). Pages: the checker, the Field Guide, Method, Privacy, About and a 404 page, in the Lightbox design.
- **The checker runs the real engine.** The site serves the engine package's browser bundle byte for byte, so the checker always runs the tested engine and the current rule pack (the general rules, with citation suppression). Moves from different rules on the same words each get their own outline, list row and stop for the loupe. The samples' moves are found by that engine when the site is built, so the page shows them without a scan; the rules are then compiled in the background, one pattern per idle moment (`prepare()` in the engine), for text of your own. A text with no marks says that the rules know set wordings and can miss the same move in other words, and links to what they miss.
- **Engine examples, rule coverage, tier labels and generated counts are checked when the site is built.** Move names come from one file (`site/data/moves.json`); the Field Guide's examples, honest versions, fair uses and every sentence its "misses" paragraphs quote are run through the engine, as are the home page's examples; the Method page's test counts are read from the tests (`scripts/site_facts.py`). The Field Guide draft was written against v1: its "misses" paragraphs are corrected for rules versions 2.0.0a2 to 2.0.0a4, and checked against the current rules at every build (`site/README.md` lists what changed). Every rule has a full entry. Tiers are written I, II and III everywhere, and the build fails on "Tier 1".
- **The page sends nothing.** Once the page, its images and its typefaces are in, its own scripts request nothing more, and they store nothing. Every page carries a Content-Security-Policy that allows only the site's own files, no fetch, XHR, beacon or WebSocket connections (`connect-src 'none'`; a policy cannot stop a page from navigating elsewhere, and the site's code never does) and, where the browser supports them, Trusted Types; and a no-referrer policy. No inline scripts or styles; no cookies or storage; the two typefaces are self-hosted, vendored from pinned `@fontsource` packages by `scripts/vendor-fonts.mjs` with their OFL licenses. Both tones' paper grain loads before the request counter starts, and the page keeps those images for its lifetime, so switching Paper and Ink (or the system's scheme), however long after load, finds them already loaded.
- **Accessible.** A mark is never colour alone: marked words also carry a solid underline in their tier's ink, and every list names the tier in words. Marks and pressed buttons stay visible in forced-colours mode. Result counts are announced; Enter on a row of the move list keeps the row on screen; below a short text, the resting loupe never covers the controls under it.
- **Link previews.** With the site's address (the Pages workflow passes it as `SITE_URL`), every page carries an `og:image` (the repository's social preview) and a large X card. These are the only absolute URLs on the pages; every link and file stays relative.
- **Tested.** `site/test/site.test.mjs` (in the `test` job and before every deploy) checks the policies, that no file loads anything from another site, that every relative link and fragment resolves, that the served bundle equals the package's and gives the same results, that the samples' stored moves are the engine's own, and every claim above. `site/test/browser.test.mjs` checks the pages in Chromium where Playwright is installed (not in CI): no error or policy violation, the counter at 0 through Paper, Ink and a text of your own, the loupe clear of the controls, a row of the move list kept on screen when Enter picks it, hostile strings pasted as a text of your own shown as literal text with no element, script or link made from them, and no long stall on a slow phone.

### Rules version 2.0.0a4 (fix round 1)

The red team's first fix round on the public seed looked where rules still hold word shapes and closed lists. Every counterexample it gave is now a test (`FIX_ROUND_1` in `tests/test_symmetry.py`, `FIX_ROUND_1_CASES` in `tests/test_e3_rules.py`), and `rules/RULE_CHANGES.md` ("Rules version 2.0.0a4") has each pair.

- **Open slots take any word shape.** `DISSENT_DISMISSAL`'s "Typical ___" frame took only a word ending in "-s" (not "-ss", "-us" or "-is"), so peoples, faiths and outlets were read by how their names are spelled; it now takes one to three words or a capitalized name, whatever its ending, before an exclamation mark ("Typical ___!"). `VAGUE_INSTITUTIONAL_APPEAL` reads a capitalized name right after "leading", "top" or "key" as the group, whatever its ending or length. `CAUSAL_TOTALIZATION` reads any plural noun phrase of one to three words that ends the clause as an object, after a determiner or bare, and its closed list of other objects holds each entry's mirror ("the welfare state" beside "the free market", "tradition" beside "progress", "the bosses" beside "the workers"); "western" left the list. `CREDENTIAL_AS_PREMISE` reads any word before "recipient", not four decoration words.
- **Closed lists hold their mirrors.** `DISSENT_DISMISSAL` adds the common-word insults aimed at the other side where one side's were marked (pro-maskers, goons, jackboots, bootlickers, storm troopers, agitators, freeloaders, moochers, welfare cheats, city slickers, snobs, elitists, yuppies, young punks, brats, old fogeys, harpies, shrews, pearl-clutchers, "<any word> nuts" in place of "gun nuts", "-botherers"), and "bosses" and "censors" as labels; neutral stance and civic role words ("activists", "advocates", "partisans", "apologists", "skeptics") are no longer labels on either side. `MEDIA_ANONYMOUS_ATTRIBUTION` adds dissidents, lobbyists, managers and members; `INEVITABILITY_FRAME` adds "tradition"; `FEAR_URGENCY` adds "occupation" beside "invasion"; `EMOTIONAL_SUBSTITUTION` reads "think of the unborn" beside "think of the children".
- **No country's statute.** `LEGAL_SANCTIONS_THREAT` no longer names one country's statute and rule number ("28 U.S.C. § 1927", "Rule 11"); the wording that raises sanctions counts in every jurisdiction, and "warranting sanctions" joins "warrants sanctions". The neutrality lint now reads "U.S." and "U.S.C.".
- **Citations of every jurisdiction.** A case name counts with or without the period after "v" ("Doe v Roe", "R v Doe"), and reporters written without periods count like dotted ones ("(2019) 17 SCC 912", "2019 SCC 97", "(1973) 912 CLR 404", "BVerfGE 912, 404").
- **Fewer false marks.** An order to disregard a thing ("Please ignore the previous email.", "Ignore the typos.") and a share of a group ("Only a third of voters would ...") are not dismissals, and a claim label that is a sentence's topic ("She studies disinformation.") is not a label. Some plain sentences are still marked, and the Method page lists them: "The fire destroyed our home.", "The frost destroyed the petals.", "The kids loved these puppets.".
- **Linear time.** `INSTITUTIONAL_POSITION_AS_SETTLED` started a sentence after a terminator and a closing quote ("?” ") while its sentence body read the same terminator as mid-sentence, so a long run of quoted dialogue took quadratic time (about 15 seconds for 20,000 characters in Python; measured 2026-09-28); `MEDIA_EMOTIONAL_LEAD` read leading whitespace two ways (over a minute for 20,000 spaces; measured 2026-09-28). Both now read each character one way. `tests/test_engine.py` and `packages/engine/test/redos.test.ts` time both, and the ReDoS guard now also tries sentence ends with closing marks, dialogue and bare whitespace. The Python timing tests take the best of three runs, as the TypeScript guard does.
- **Pairs judged again.** The two lowercase-name limits of rules 2.0.0a3 ("destroying Catholics" / "destroying evangelicals") now pass. One new pair is a known limit ("Those rioters ..." / "Those pigs ...": "pigs" is also the farm animal). Two pairs are retired ("They're just populists." / "They're just elitists.", a movement's name against a dismissal word; "They are election deniers." / "They are election skeptics.", a dismissal word against a neutral stance word), and two pairs that set a stance word against a movement's name ("abolitionists", "prohibitionists") have their own reason. That leaves **20 known limits** and **48 retired pairs**. The symmetry templates now put every swapped name inside the frames and slots above: 135 pairs of names and labels, 8,313 template pairs.
- **The neutrality lint reads disguised words.** It reads each regex a second time the way someone hiding a word would write it: a hyphen inside a blend ("neo-cons"), a class with a digit or many letters in place of one letter ("soc[i1]alists", "m[aeiou]slims") and one wildcard letter ("soc.alists"). Its reference list adds the prefixes "crypto", "post", "pseudo", "far" and "paleo" and the families the red team found missing, and a mutation test inserts each disguise.
- **The sdist and the release.** Tests that read repository-only files (the site, the TypeScript engine, the images) skip in the sdist, the sdist leaves out the site's build scripts, and the release workflow runs the tests from the sdist before it uploads. The build tools are installed from `.github/requirements-release.txt`, pinned by hash with every package they need. PyPI shows its own readme (`docs/PYPI_README.md`), with absolute links.
- **Website.** The three rules rebuilt from v1 have full Field Guide entries. The request counter stays at 0 when Paper and Ink switch long after load. On a short first screen the checker shows the loupe, the count and the list at once instead of waiting for the text to scroll into view, and never draws the film without its loupe. The 404 page's links are anchored at the site's base path, so it is styled at any depth. Without JavaScript the home page lists the first sample's moves and hides the controls that need a script.

### Rules version 2.0.0a3 (site review)

- **Linear time on long runs of name characters.** Citation suppression's author-year pattern let a name token hold the en and em dash that also join names, so a claim followed by "(" and a chain of dash-joined words could be split in exponentially many ways: 30 words took about 40 seconds in V8, and longer in Python (measured 2026-09-28). A name token no longer holds a dash; the dash between names still joins them, so every citation read before is read the same. The fifth round's wider citation names (any script, "%" and "!") keep this: each character of a name has one way to be read, in the author-year pattern and in the pattern for a name before a page number. `CREDENTIAL_AS_PREMISE` reread a long run of name characters from every word boundary inside it (quadratic time: 20,000 characters took several seconds (measured 2026-09-28)); the award name before "-winning", "winner", "recipient" or "Fellow" now starts a token and holds a capital letter and up to 40 more characters. On every golden and symmetry text the moves are the same.
- **Red team, site review.** `DISSENT_DISMISSAL` read a group's own name as a label without its mirror in three pairs, and a faith's own name was not on its list. The mirrors were added first; the change below then took every group's name out, so all five of the review's pairs now pass, the faith-name pair included.
- **Rules hold no group names.** By design, no rule holds a word that names, or is built from the name of, a person, party, movement, ideology, faith, country, program, outlet, institution or school, in any form (plurals, "-ist", "-ism" and "-ite" forms, "anti-", "neo-", "ultra-" and "pro-" forms, slur blends), with one exception that decides only where a sentence ends: the shared list of abbreviations that do not end a sentence holds titles of every major faith and both parties' "Rep." and "Dem.", treated alike (see "Same rules for every side" below); the neutrality lint checks every rule against a reference list of such words, and the swapped pairs check what a list cannot hold. Mirroring a list of groups does not make it neutral, so the lists are gone:
  - `DISSENT_DISMISSAL` marks dismissal words that can be aimed at anyone, wherever they appear, each beside its mirror where a word is aimed at one side ("crackpots", "trolls", "useful idiots", "ideologues" and "propagandists" are new); role words ("radicals", "fanatics", "partisans", "bots") where a text applies them as a label; and a group's own name only inside an open frame that takes any word: "Only a ___ would say that", "Of course the ___ would say that", "That's just what the ___ want you to think", "Typical ___s!" and "Ignore the ___.". Each frame was judged against lines that must stay unmarked ("They're just kids.", "Ignore the noise from the fan.", "Of course the kids want pizza."); the object of "Ignore the" is now one to three words that are not function words, or a capitalized name, and it ends the clause. (Rules 2.0.0a4 changed the "Typical" frame and the role words; see above.) Its group names, slur blends of names, faith words for outsiders and "-tards" are gone.
  - `CAUSAL_TOTALIZATION` drops named programs, systems, ideologies and faith stances from its objects, reads any word ending in "-ism" as an object by its shape, and reads "<anyone> is the cause of all / every ..." and "... to blame for everything" with any subject and object.
  - `MEDIA_ANONYMOUS_ATTRIBUTION` drops four identity and movement words from its stance words.
  - The closed list of abbreviations that do not end a sentence drops a country's abbreviations, and a citation pattern drops the country's. (It dropped a party's too, until the change below put it back beside the other party's.)
  - `tests/test_neutrality_lint.py` fails if any rule holds a word from its reference list of such names and the words built from them, reading each regex as the words it can spell and each name and description as text; a mutation test adds one such word to a rule and requires the lint to fail. On the 521 v1 golden texts no move changed. `NAME_FREE_RULES` and `NAME_FREE_CASES` hold the pairs and examples written with the change. The Field Guide entries for the two changed rules say what they now catch and miss.
- **Same rules for every side.** A swapped pair must swap the side and keep the kind of word. Red-team pairs that change the kind of word instead (a dismissal word against a group's own name, "experts" against "historians", "critics" against "Catholics", "history" against "God", a common noun against a faith's own word) are not mirrors. They are retired: kept with a one-line reason in `RETIRED_PAIRS` (`tests/test_symmetry.py`, listed in `rules/RULE_CHANGES.md`, "Same rules for every side"), and neither run nor counted as limits; where one has a true mirror, the mirror runs. That left 21 known limits (measured 2026-09-28), pairs where the same kind of wording is marked for one side and not the other, and 46 retired pairs (measured 2026-09-28); `scripts/site_facts.py` counts both, and the site and the README quote the current counts.
  - `DISSENT_DISMISSAL` marks "book banners" and "book burners" beside "groomers": where an insult aimed at one side is marked, a common-word insult aimed at the other side is marked too, never a word built from a name.
  - The two parties' abbreviations are treated alike: "Dem." is back on the closed list of abbreviations beside "Rep.", and the neutrality lint allows exactly these two dotted forms, inside that list only. No country's or nationality's abbreviation is on the list ("Amer.", "Am.", "Brit." each end a sentence alike); "Fr." and "Ind.", on it as a title and a state, make the nationality pairs with those spellings known limits.
  - No rule holds a faith's own word for its places and offices. `CAUSAL_TOTALIZATION` counts "the clergy", "the congregations", "worshippers" and "houses of worship" for every faith, where it listed churches, mosques, synagogues, temples, pastors, imams, rabbis and the like; `MEDIA_ANONYMOUS_ATTRIBUTION` reads "worshippers" where it read "parishioners". The title abbreviations hold every major faith's ("Rab." joins "Rev.", "Fr.", "Sh.", "Ust.", "Shri." and "Ven."), and a lint test checks it.
  - The lint's reference lists are marked as denylists and kept in plain text. They hold faith-specific nouns and eponym forms again, including ones built from living people's names, which a test allows in that file only.
- **Field Guide examples show one move each.** Some examples also raised another rule ("completely destroyed the community garden" was `CAUSAL_TOTALIZATION`'s move too); each now shows only its own, and the site build fails when an example, in its entry's domain, raises any other rule, or an honest version raises any rule.
- **No real organization in a description.** `INSTITUTIONAL_POSITION_AS_SETTLED`'s description gives invented subjects as examples.
- **Tests.** Timed regression tests for the slow patterns (`tests/test_engine.py`, `packages/engine/test/redos.test.ts`), and the ReDoS guard now also tries a bracket followed by a chain of words joined by each punctuation mark in a pattern, and a bracket followed by a run of one non-ASCII letter. `RED_TEAM_SITE_REVIEW` holds the review's pairs and five more written with the fix, and `SITE_REVIEW_CASES` in `tests/test_e3_rules.py` its positive and negative examples. A pair listed twice in `tests/test_symmetry.py` is listed once: 135 pairs of names and labels (7,410 template pairs then; measured 2026-09-28).
- **TypeScript engine.** The bundled rules are compiled when a scan first needs them, and the new `prepare()` does the same ahead of time, one pattern per call, so a page can spread the work over short tasks. Results are unchanged.

### Rules version 2.0.0a2 (structural rules and symmetry)

Rules read names more alike: with rules 2.0.0a4, 9,793 swapped pairs raise the same rules on both sides (8,313 template pairs and 1,480 red-team pairs), 20 known limits are listed with their reasons, and name slots and gaps hold up to 16 tokens, so a longer name can still stop a match (`scripts/site_facts.py` counts the pairs). 38 known limits remained at the end of E3 (measured 2026-09-28), before rules 2.0.0a3 fixed some and retired the pairs that were not mirrors. `rules/RULE_CHANGES.md` has the full account, with every pair; this is the summary, by structure.

- **Three rules restored without name lists.** `CREDENTIAL_AS_PREMISE` replaces v1's `CREDENTIAL_AS_PROOF` (any school, award or role counts the same). `INSTITUTIONAL_POSITION_AS_SETTLED` replaces the named-agency part of v1's `INSTITUTIONAL_NEUTRALITY` ("<any organization> has concluded that ...", with no evidence clause in the sentence), and `NEUTRALITY_CLAIM` brings back its structural part ("as a neutral third party"). `FIN_CHERRY_PICKED_TIMEFRAME` is back: month names are calendar words, not entities.
- **Windows counted in words, the same for every name.** Name slots and gaps hold up to 16 name tokens (32 words for "either ... or"; slots held 8 until the red team's fifth round), in `CONSENSUS_AS_EVIDENCE`, `CREDENTIAL_AS_PREMISE`, `SOFT_CONSENSUS`, `VAGUE_INSTITUTIONAL_APPEAL`, `COMPETENCE_DISMISSAL`, `MONOCAUSAL_BLAME`, `FALSE_BINARY`, `MEDIA_EDITORIAL_AS_NEWS`, `MEDIA_FALSE_BALANCE` and `FIN_SURVIVORSHIP_BIAS`. A name token may hold abbreviation periods, domain names, "!", curly apostrophes and en dashes, so punctuation in a name no longer breaks a match. `MEDIA_EMOTIONAL_LEAD` looks at the whole first sentence.
- **A name's own words no longer trigger a rule.** In `CONSENSUS_AS_EVIDENCE`, `CLAIM_WITHOUT_CITATION`, `SHAME_LEVER` and `INEVITABILITY_FRAME`, a capitalized trigger word counts only at the start of a sentence, not at the end of a name.
- **Word lists hold both sides' words.** `DISSENT_DISMISSAL` holds a mirror for each insult and claim label it lists (the list is in `rules/RULE_CHANGES.md`). `MEDIA_EDITORIAL_AS_NEWS`, `VAGUE_INSTITUTIONAL_APPEAL`, `MEDIA_WEASEL_QUANTIFIERS`, `MEDIA_FALSE_BALANCE`, `NEUTRALITY_CLAIM`, `CAUSAL_TOTALIZATION`, `FEAR_URGENCY`, `COMPETENCE_DISMISSAL` and `CONSENSUS_AS_EVIDENCE` now count unions beside companies, labor beside industry, the planet beside the economy, supporters beside opponents, and any plural noun where only a few professions counted.
- **Any subject can state a settled position.** `INSTITUTIONAL_POSITION_AS_SETTLED` reads any subject, capitalized or not, so "the unions have concluded that" reads like "the agency has concluded that".
- **Citation look-alikes fixed.** Citation suppression no longer reads the end of a word or name in "id.", "said.", a company name that starts with a Latin citation word or with "Figure", an abbreviation such as "gov't" or "Fed." with no number after it, a page reference inside a model name, or a year before a ranking as a citation; and it now reads author-year citations whose names hold "&", hyphens or two or more words. This also changes `TOTALIZING_HARM_LANGUAGE`, whose regex is unchanged, and `MEDIA_ANONYMOUS_ATTRIBUTION`, whose regex the red team's second, third and fifth rounds and rules 2.0.0a3 changed as well.
- **Red team, second round.** 301 more swapped pairs; 297 passed as required checks and 4 ran as strict expected failures with written reasons (measured 2026-09-27) (`rules/RULE_CHANGES.md`, "Red team, second round"). A one-word surname ends a sentence the same way for every name (only closed-class abbreviations and initials continue one); lowercase abbreviations no longer break a window; names that contain an evidence word or a rule word ("Review", "Research", "Progress", "Points", "Day", "History") no longer block or trigger a rule; group words need no plural "s"; and closed noun lists became open slots or hold both sides (`VAGUE_INSTITUTIONAL_APPEAL`, `MEDIA_EDITORIAL_AS_NEWS`, `COMPETENCE_DISMISSAL`, `MEDIA_FALSE_BALANCE`, `NEUTRALITY_CLAIM`, `MEDIA_ANONYMOUS_ATTRIBUTION`, `CREDENTIAL_AS_PREMISE`, `DISSENT_DISMISSAL`, `CAUSAL_TOTALIZATION`, `MEDIA_SELECTIVE_QUOTATION`). `MORAL_HIGH_GROUND` becomes a changed rule. More citation look-alikes fixed (page and docket abbreviations, "v." case names, long author-year names, en dashes and commas in school names).
- **Red team, third round.** 243 more swapped pairs; 240 passed as required checks and 3 ran as strict expected failures with a written reason (measured 2026-09-27) (`rules/RULE_CHANGES.md`, "Red team, third round"). `DISSENT_DISMISSAL` adds the mirrors the red team found, reads a label after "neo-" or "eco-", and reads a capitalized label after a capitalized word. Closed noun lists became open slots: "<anyone> overwhelmingly agree", "no serious <any noun> believes", "unnamed <any noun>", "any reasonable <any noun> knows", "no decent <any noun> would", "every <any word> knows", "lack the wisdom / faith to", "every successful <any role> has", "time-honored doctrine / teaching / law"; `CAUSAL_TOTALIZATION` held every faith's houses of worship (rules 2.0.0a3 put faith-neutral words in their place) and holds both sides' institutions and livelihoods; `VAGUE_INSTITUTIONAL_APPEAL` reads group nouns without an "s", "unions" and "companies" beside "groups", and group names with "+"; `CREDENTIAL_AS_PREMISE` reads any award's name before "winner", "recipient" or "Fellow". A capitalized idiom, pronoun, evidence or intensifier word inside a name no longer counts. The AP abbreviations of every state and school words no longer end a sentence. A citation counts when any part of it is within 120 characters of the claim, so a long organization name inside it is seen like a short one, and citation names may hold "/", "+", "*", "@", "#", curly quotes, em dashes, bracketed or nested acronyms, numbers and ";". `APPEAL_TO_TRADITION` and `EMOTIONAL_SUBSTITUTION` become changed rules.
- **Red team, fourth round.** 183 more swapped pairs; 181 passed as required checks and 2 ran as strict expected failures with a written reason (measured 2026-09-28) (`rules/RULE_CHANGES.md`, "Red team, fourth round"). `DISSENT_DISMISSAL` no longer reads a group's own name as a label wherever it appears: insults count anywhere, with the missing mirrors added; a group's own name counts only where the text applies it as a label ("they're just <label>", "he called them <label>", "they are <label>", "those <label>", "Only <label> ..."); claim labels count at the end of a phrase, not inside a name; and an order to disregard ("Ignore the <anything>.") counts with any object.
